VIEW, REFRESH AND INSTALL

VIEW
Open final-entry/final-lock-screen.png in Preview. The cover is final-entry/cover.png. exports/current contains a reduced-size preview and a clearly labeled generic laptop mockup. A mockup is not an installed-device screenshot.

REFRESH
The PNG is static. It does not update in the background.
Double-click Refresh.command from the project folder, or run:
.venv/bin/python scripts/refresh.py
This uses the current instant and Asia/Kolkata calendar dates, creates dated exports and updates the proposed final PNG/cover. It does not change your wallpaper, completion ledger, reminders or public repository. If exporting a new submission edition, regenerate the PDF summary as described in scripts/README.txt and publish the files deliberately after review.

FIRST SETUP ON ANOTHER COMPUTER
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/refresh.py
The only core third-party dependency is Pillow11.3.0. Bundled Lexend font and OFL license are included. Python3.10+ with IANA timezone data is required; current local environment was tested. PDF authoring also uses reportlab; it is not required for ordinary wallpaper refresh.

DATE CONVENTION
Days remaining is the difference between local calendar dates in Asia/Kolkata, not rounded24-hour blocks. On20 November before20:00 IST: Due today. At20:00 IST and later: Deadline passed unless completion has actually been recorded with evidence. Export date/time is printed unobtrusively. Future previews are labeled and preserve the actual completion ledger.

RECORDING WORK
Edit config/project.json only after real evidence: milestone completed=true plus an evidence path. Record a task separately with its own evidence. Set device_validated=true only after a real lock-screen observation. Completion.recorded is independent of the countdown. Do not mark stages complete to make the image look finished. Keep config/daily-actions.json synchronized with the tasks array.

MAC CHECK (about10 minutes)
1. System Settings > Wallpaper > Add Photo, then choose final-entry/final-lock-screen.png. UI wording may vary by macOS version. Keep the complete image visible; use Fit if available.
2. Choose Apple menu > Lock Screen (or Control-Command-Q). Check the actual clock, controls and crop. Read the action/fallback at your usual distance. The display resolution was freshly observed as2560x1664; resolution alone does not prove fit.
3. Unlock and record the observation/date or one concrete issue. A photo is optional evidence; crop personal account/notification details before sharing. No screenshot is included unless genuinely captured.
This workflow changes the normal wallpaper; it does not modify FileVault, loginwindow caches or system security.
