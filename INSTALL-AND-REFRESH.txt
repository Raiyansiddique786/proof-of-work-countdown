VIEW AND INSTALL THE SHARED EDITION
The shared review image is final-lock-screen.png at the repository root. Open its GitHub file page and use Download raw file, or download the repository ZIP and extract it.
On the Mac, open System Settings > Wallpaper > Add Photo and select the PNG. Then choose Apple menu > Lock Screen (Control-Command-Q). Inspect real clock/control overlap, cropping and normal-size text. The native2560x1664 resolution is confirmed; actual installed fit remains pending. The device-mockup.png image is illustrative.

REFRESH LOCALLY
From the extracted source directory:
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/refresh.py
After first setup, source/Refresh.command is a convenient Mac launcher.
New full images and previews appear in source/exports/current. The proposed refreshed wallpaper and cover appear in source/final-entry. Select the new image manually in Wallpaper settings.
This command does not publish changes to GitHub, alter device settings, configure reminders or record completion. The PDF at the repository root is a dated release snapshot; do not describe it as a live document.

ACCURACY
The countdown uses Asia/Kolkata calendar dates and an unambiguous deadline instant. On the target date before20:00IST it says Due today; at/after20:00IST it says Deadline passed unless actual completion is recorded. Update configuration only with real work evidence. Time passing never fills a milestone.
The bundled Lexend font is supplied with its SIL Open Font License. Core export needs Python3.10+ and Pillow11.3.0. Reminders are optional and unconfigured.
