DATE AND STATUS CONVENTION
Days remaining is the difference between local calendar dates in Asia/Kolkata, not rounded 24-hour periods. The 18 November edition shows 2 days until the 20 November target. On the deadline date before 20:00 IST, the due-today state applies. At/after the exact cutoff, an unfinished goal shows Deadline passed; recorded completion governs the completed state. A zero countdown never proves success.
Five completed project stages and a recorded release do not mean a contest entry was submitted. The current next action is manual Handshake submission; its fallback is to review the cover and description. Evidence, not time, controls completion.

SETUP ON ANOTHER COMPUTER
  python3 -m venv .venv
  .venv/bin/python -m pip install -r requirements.txt
  .venv/bin/python scripts/refresh.py
The core image dependency is Pillow 11.3.0. Lexend and its OFL license are bundled. Use Python 3.10+ with IANA timezone data. PDF authoring also uses ReportLab; ordinary wallpaper export does not require it.
